# Usar cursos nos Estudos

1. Abra **Estudos → Cursos → + Criar curso** e indique nome e descrição.
2. Toque em **Abrir curso → + Criar módulo ou disciplina**. Escolha o tipo, dê um nome e confirme o curso.
3. A biblioteca dessa unidade abre. Toque em **Importar materiais** para escolher um ou vários ficheiros no telemóvel. Os materiais ficam como cópias locais.
4. Use **Cadernos, Cartões, Perguntas e Agenda** para criar as atividades da unidade; em **Visão geral** há revisão e sessão de foco. **Progresso** reúne os registos existentes da unidade/curso selecionado.
5. Para organizar uma disciplina anterior, abra **Todos os estudos → Módulos**, toque na engrenagem da disciplina, escolha **Editar módulo ou disciplina** e selecione o curso. Os materiais acompanham a unidade sem voltar a copiá-los.

A engrenagem do curso permite editar ou remover o curso. Remover a organização conserva os conteúdos em Todos os estudos; não elimina os documentos originais. Antes de atualizar, exporte uma cópia dos Estudos. Backups criados pela 5.2 precisam da 5.2 ou versão posterior para recuperar cursos.
